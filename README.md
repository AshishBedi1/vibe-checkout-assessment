# Vibe Shop — Savyre assessment repository

E-commerce flow (search → filter → cart → coupon → checkout) for **vibe coding** assessments in Savyre.

## Branches

| Branch | Purpose |
|--------|---------|
| `main` | Golden reference — all E2E tests pass |
| `bug/vibe/multi-checkout/v1` | Assessment branch — catalog, cart, and checkout bugs |

## Commands

```bash
npm install
npm run dev
npm run test:e2e
```

See `MAINTAINERS.md` on the bug branch for the intentional defect list.
